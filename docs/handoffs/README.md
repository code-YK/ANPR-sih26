# Branch Handoffs

Handoff files are temporary, branch-scoped recovery packets for unfinished work. Use `TEMPLATE.md` and name the file after the task ID, for example `ING-003.md`.

Rules:

- Keep the packet factual and current.
- Record exact commands and outcomes.
- Link durable decisions to ADRs instead of repeating them.
- Never include secrets, private endpoints, personal data, or footage.
- Remove or mark the handoff superseded when the PR is merged and canonical docs contain the durable result.
