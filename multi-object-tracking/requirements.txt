# IMPORTANT: install PyTorch from the CUDA index FIRST, before this file.
# A plain `pip install torch` on Windows silently installs a CPU-only wheel,
# which runs ~15x slower with no error message.
#
#   pip install --index-url https://download.pytorch.org/whl/cu128 torch torchvision
#
# cu128 or newer is required for RTX 50-series (Blackwell, sm_120).
# Verify with:  python -c "import torch; print(torch.cuda.is_available())"

# Target interpreter: Python 3.11, matching backend/requirements.txt.
#
# NOTE (verified 2026-09-12): these lower bounds are a working baseline, not a
# reproducible lock -- see ADR 0002. On a fresh install today they resolve to
# ultralytics 8.4.149 and **opencv-python 5.0.0.93**, a major-version jump from
# the 4.x this range was written against. Everything imports and cv2.imshow
# works, but no worker has been run end to end against OpenCV 5 for long.
# If you hit an unexplained cv2 behaviour change, check this first.

ultralytics>=8.4.63
opencv-python>=4.8.0
numpy>=1.24.0

# --- number plate recognition (optional, for --plates) -------------------
# fast-alpr pulls in opencv-python-headless, which SHADOWS opencv-python and
# silently breaks cv2.imshow. After installing, restore the GUI build:
#   pip install fast-alpr
#   pip uninstall -y opencv-python-headless
#   pip install --force-reinstall --no-deps opencv-python
#
# onnxruntime-gpu must match torch's CUDA major version or it falls back to
# CPU with only a log line to show for it (~90ms/crop instead of ~2ms).
# torch cu128 ships CUDA 12, so pin the CUDA 12 build:
#   pip install onnxruntime-gpu==1.22.0
fast-alpr>=0.4.0
onnxruntime-gpu==1.22.0
